# Final Workflow Architecture — Sadan Rai Archive

## 1. Public research structure
**Research & Sources** is the main evidence/research area.

**Sadan Rai — Original Research & New Findings** is a separate first-class layer for genuinely new field findings and original observations.

Public pages explain the research state clearly without exposing private admin working notes.

## 2. Admin structure
Admin opens as a clean Command Center with:
- Primary Original Research entry
- Shared Research Workflow
- Research status overview
- Workspace navigation
- Quick creation actions
- Dedicated 20-section Kirat research workspace
- Research Library
- Public Content CMS
- Additional Archive management

## 3. Record workflow
**Source / Lead → Original Observation → Evidence → Independent Cross-check → Evidence Assessment → Researcher Analysis → Conclusion / Further Research → Publication → Version History**

## 4. Original Research workflow
**Field Finding → Original Observation → Original Evidence → Existing Research Link → Independent Cross-check → Evidence Assessment → Researcher Analysis → Conclusion → Publication → Version History**

## 5. Evidence integrity
- Source statements remain distinct from researcher conclusions.
- Oral tradition remains identified as oral tradition unless independently supported.
- A new finding is not automatically historical fact.
- Exact page/folio/object references must be used where available.
- No evidence is invented.

## 6. Navigation
Every non-dashboard Admin workspace has a breadcrumb/back path to the Workspace Home. Command palette access is available through **Ctrl/⌘ + K** or **/** when not typing in a field.
