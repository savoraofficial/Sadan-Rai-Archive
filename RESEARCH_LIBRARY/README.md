# SADAN RAI — Research Library

This folder is a separate research/evidence library for the SADAN RAI Archive.

## Master preservation rule
The existing application code, features, functionality, configuration, public assets, and existing project content in this ZIP are preserved as supplied. This research library is additive and independent of the application code.

## Workflow
Research Library → Evidence Verification → Published Archive/Web

Use this area to collect books, papers, manuscripts, archival records, maps, scans, oral-history records, notes, and evidence analysis before publication.

## Evidence levels
- E1 — Primary / original or near-contemporary evidence
- E2 — Archival manuscript / archival record
- E3 — Chronicle / genealogy / later historical record
- E4 — Oral tradition / Mundhum / community tradition
- E5 — Modern interpretation / hypothesis

Do not treat an E3/E4/E5 claim as E1/E2 evidence without independent support.
